# Documentation Assets

This folder contains screenshots and documentation assets for the README.

## Screenshots Needed

To complete the README, add these screenshots:

1. **screenshot-upload.png** - Upload screen showing:
   - Mode selector (CRM/Universal toggle)
   - Drag and drop zone
   - Dark theme with glassmorphism

2. **screenshot-processing.png** - Processing screen showing:
   - Animated spinner
   - Progress indicator
   - "AI is mapping your data" message

3. **screenshot-results.png** - Results screen showing:
   - Summary bar with stats
   - Imported records table
   - Skipped records table (if any)

## How to Add Screenshots

1. Take screenshots of your running app at http://localhost:3000
2. Save them to this folder with the exact filenames above
3. Screenshots will automatically appear in the README

## Recommended Screenshot Tool

- **Windows**: Snipping Tool or Greenshot
- **Mac**: Cmd+Shift+4
- **Linux**: Flameshot or GNOME Screenshot

## Image Guidelines

- Format: PNG
- Resolution: 1920x1080 or higher
- File size: Keep under 1 MB each
- Show real data (use test CSVs from `test-csvs/` folder)
